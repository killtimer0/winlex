# GUI 设计

## 模块职责

- `app.rs`：UI 线程状态、字体缓存生命周期、启动与消息循环。
- `app/frame.rs`：公共控件、命令分发、主窗口布局和根 DPI 通知。
- `app/workspace.rs`：文档创建/关闭、文档标签、MDI 激活同步、排列。
- `app/document.rs`：文档控件、内容更新、内部页面、焦点恢复。
- `dpi.rs`：DPI 能力探测、旧系统回退、字体和非客户区度量。
- `layout.rs`：几何计算和逻辑位置；`native.rs`：原生操作辅助。
- `resources.rs`、`res/`：语言选择及原生资源。

## 状态与消息

所有 HWND 操作在 UI 线程进行。先读取所需状态并结束借用，再调用 Win32；
状态修改闭包内不得调用可能同步重入窗口过程的 API。

MDI 是活动文档的唯一来源，标签仅映射文档列表。应用发起的创建/关闭集中到工作区；
文档最终移除发生在 `WM_NCDESTROY`，原生默认处理完成后同步标签、投递排列请求。

标题、内容、页面选择、布局分别更新。切页只切换可见控件，不重建内容；
架构改变更新标题和内容。文档布局只管理自己的子控件。

主窗口 DPI 通知按资源更新、建议窗口矩形、公共布局、文档布局的顺序处理。
保留原生 MDI 默认消息处理；自由排列的位置只在用户操作边界记录。

## 资源约定

固定 UI 文案放入 `res/en-US.rc` 和 `res/zh-CN.rc`；菜单使用原生 MENU 资源。
协议值、窗口类名、技术诊断及最小错误兜底可保留在代码中。
`resource.h` 是资源和命令 ID 的唯一来源，构建时生成 Rust 常量。
固定选项集中定义模型值和显示资源 ID，不能从翻译后的文案推断模型值。

语言在启动时选择：`auto` 使用系统 UI 语言，简体中文使用中文资源，其余回退英文；
也可指定 `en-US` 或 `zh-CN`。直接按语言读取原生资源，兼容 XP，不依赖新版线程语言 API。

`gui.rc` 统一嵌入菜单、字符串、版本信息和清单；版本信息来自 Cargo 包版本。
清单声明 common-controls v6、asInvoker 和系统兼容性，DPI awareness 由运行时选择。
资源文件使用 UTF-8，RC 显式指定代码页；换行遵循本仓库 `.gitattributes`。

验证包括双语资源完整性、占位符一致性、实际控件文案、选项往返映射及切页状态保持，
运行方式见[构建与验证](build.md)。
