# GUI 使用指南

## 打开与管理文件

通过“打开文件”（Ctrl+O）、来源面板的打开按钮或拖放，打开一个或多个 WinMD 文件。
加载完成后即可搜索其中的符号。来源列表第一行显示文件图标和加粗文件名，第二行显示加载状态、易读大小和所在目录。
悬停可查看完整路径和精确字节数；目录过长时保留末尾部分。
选中来源后可重新加载或关闭，也可通过右键、菜单键或 Shift+F10 打开菜单，复制完整路径。
重新加载时显示进度状态，失败时保留原来源，并可在悬停提示中查看原因。当前已加载的数据仍可继续使用。
刷新后保留选中来源与滚动位置，关闭选中来源后选择相邻项。

普通启动会恢复上次成功打开的来源集合；首次启动时可自行选择文件。
使用 `winlex-gui [FILE ...]` 启动，可指定一个或多个文件，也可将文件拖到 EXE 或快捷方式上启动。
指定文件路径启动的是临时会话，其中的来源操作不影响普通启动时恢复的集合。

## 搜索与预览

输入查询后会自动搜索，按 Enter 可立即执行搜索。右侧下拉框提供两种方式，切换时保留当前输入：

- **快速搜索**（默认）：同时尝试模糊名称、数字等值、字符串常量子串和 GUID，每个实体只显示一次；GUID 自动识别要求至少 4 个规范化十六进制字符。
- **条件搜索**：明确指定字段和操作，例如 `name contains "access" and value = 5`、`value contains "Windows"`、`value >= 1.45 and value < 1.55`、`value = nan or value = inf`。支持 AND、OR、NOT 和括号。

名称不区分大小写。快速搜索支持按顺序输入不连续字符；查询不含 `.` 或 `+` 时匹配短名称，否则匹配完整限定名；末尾 `.`／`+` 可浏览名称范围。条件中的 `name` 和 `fullname` 明确指定字段。
数字 `5`、浮点数 `5.0` 和字符串 `"5"` 含义不同；浮点等值 `1.5` 与 `1.50` 等价，范围需显式指定。`nan` 匹配任意 NaN，`inf`／`-inf` 匹配正负无穷。
悬停搜索框可查看当前搜索方式的简要语法和示例。输入未完成或条件无效时，状态栏提示错误并清空旧结果。通过“帮助 → 搜索语法…”查看完整说明，完整规则见 [CLI 与查询接口](cli.md)。
快速搜索优先显示精确命中，其次为 GUID 片段、文本匹配和模糊名称；模糊名称按匹配度排列。同级和组合条件按来源与记录标识排列。

结果第一行以类别图标和较大加粗字体显示名称，第二行显示常量值或所属类型、架构及命名空间。同时支持 x86、x64 和 arm64 时省略架构，否则列出支持的架构。GUID 使用 `{...}` 表示，完整 GUID 可在详情查看。
名称及字符串匹配强调对应字符，数字匹配强调整个值，GUID 匹配强调 `{...}`。多个字段命中时分别强调；选中或使用高对比度模式时，匹配部分带下划线。
悬停可查看完整名称、来源路径和记录标识；不同来源的同名实体保留独立结果。

- 单击结果或按空格预览声明。连续预览会复用同一个标签，方便快速浏览。
- 双击结果或按 Enter，可固定文档并进入正文。
- 双击预览标签也可将其固定。
- 按 Ctrl+Enter，可在新文档中打开结果，创建副本用于并排比较。
- 再次打开相同来源版本和架构的同一符号，会切换到已有文档。

标签显示图标和标题，预览标签使用斜体，悬停可查看完整标题。中键、右键菜单或 Ctrl+F4 可关闭文档，拖动标签可调整顺序；标签较多时可用滚轮横向滚动。
标签栏获得焦点后，左右键切换标签，Home／End 跳到首尾，Ctrl+Shift 配合这些键可调整标签顺序，Enter 进入正文；右键、菜单键或 Shift+F10 打开标签菜单。选中的标签会自动滚入可见区域。
“窗口”菜单提供关闭文档、平铺、自由排列和最大化操作。
侧栏按钮可切换或折叠面板；Ctrl+L 将焦点移到搜索框，F6 在侧栏、标签栏与文档之间切换。

## 阅读声明

正文包含完整名称、来源路径、记录标识和 C/IDL 风格的声明，采用等宽字体和语法着色，便于阅读与复制。
声明是元数据的阅读表示，不保证能作为头文件直接编译。

架构下拉框列出符号支持的 x86、x64、ARM64 架构，每个文档可独立选择。
打开其他结果时，会优先沿用当前文档的架构；不适用时使用保存的偏好或符号支持的架构。
按 Ctrl+Enter 打开的新文档使用保存的架构偏好。

声明注释包含结构体大小、对齐、字段偏移，以及接口槽位和 vtable 偏移。
数值对应当前选择的架构，同时显示十进制与十六进制；无法计算时会显示原因。

声明后附有属性、GUID、导入、参数和成员等元数据。正文均可选择复制。

在正文中右键可复制选中文本；指向数值时，还可复制十进制、十六进制或带单位的值。
也可使用菜单键或 Shift+F10 打开上下文菜单。

带下划线的类型引用可按 Ctrl+单击跳转，也可通过右键菜单的“转到声明”打开。
光标位于引用内时，菜单键或 Shift+F10 提供同一操作。普通单击、双击和拖动用于选择文本。
跳转使用来源文档的元数据快照和架构，保留来源文档，并固定目标标签；目标已打开时切换到已有标签。
只有当前快照能唯一解析的类型提供跳转。

## 来源更新与已打开文档

文档保留打开时的内容快照。关闭或重新加载来源后，已有文档的正文保持不变，
仍可切换架构查看该快照的声明。

重新加载来源后，旧文档会显示旧快照提示。从搜索结果打开符号即可查看更新后的内容，
也可以保留旧文档进行比较。

## 界面与设置

通过“文件 → 设置…”打开设置窗口。

设置窗口可更改界面语言，并按条目类别筛选搜索结果。
确定后保存修改，取消则放弃修改。语言更改在重启后生效，搜索筛选立即生效，
不影响已打开文档的内容。

窗口布局、来源集合和架构偏好会自动保存。

界面随显示缩放调整尺寸，字体跟随系统设置；高对比度模式下使用系统文字颜色。
构建、测试及系统兼容性信息见 [构建与验证](build.md)。
