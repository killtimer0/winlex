# GUI 使用指南

## 打开与管理文件

通过“打开文件”（Ctrl+O）、来源面板的打开按钮或拖放，打开一个或多个 WinMD 文件。
选中来源后可重新加载或关闭；右键菜单可复制完整路径。悬停可查看完整路径或加载失败原因。重新加载失败时保留已加载的数据。
“帮助 → 获取元数据…”在浏览器中打开 winmd-collection 的发布页面，按对应发布说明下载并解压 WinMD。
查询跨文件引用的类型时，需要将相关 WinMD 一起打开。

普通启动会恢复上次成功打开的来源集合；首次启动时可自行选择文件。
使用 `winlex-gui [FILE ...]` 启动，可指定一个或多个文件，也可将文件拖到 EXE 或快捷方式上启动。
指定文件路径启动的是临时会话，其中的来源操作不影响普通启动时恢复的集合。

## 搜索与预览

输入查询后会自动搜索，按 Enter 可立即执行搜索。右侧下拉框提供两种方式，切换时保留当前输入：

- **快速**（默认）：搜索名称、常量值和 GUID。
- **条件**：指定字段和操作，例如 `name contains "access" and value = 5`。

悬停搜索框可查看语法示例，输入无效时状态栏提示错误。通过“帮助 → 搜索语法…”查看说明，搜索匹配与条件表达式规则见 [CLI 使用指南](cli.md)。

不同来源的同名实体分别列出；悬停可查看完整名称和来源。

- 单击结果或按空格预览声明。连续预览会复用同一个标签，方便快速浏览。
- 双击结果或按 Enter，可固定文档并进入正文。
- 双击预览标签也可将其固定。
- 按 Ctrl+Enter，可在新文档中打开结果，创建副本用于并排比较。
- 再次打开同一符号时，会切换到对应架构和来源版本的已有文档。

结果的右键菜单可打开文档、在新窗口打开或复制名称和值；整数支持十六进制复制。适用的整数还可直接“搜索错误码”。所有上下文菜单也可用菜单键或 Shift+F10 打开。

预览标签使用斜体，悬停可查看完整标题。中键、右键菜单或 Ctrl+F4 可关闭文档，拖动标签可调整顺序；标签较多时可用滚轮横向滚动。
标签栏获得焦点后，左右键切换标签，Home／End 跳到首尾，Ctrl+Shift 配合这些键可调整标签顺序，Enter 进入正文；右键、菜单键或 Shift+F10 打开标签菜单。
“窗口”菜单提供关闭文档、平铺、自由排列和最大化操作。
侧栏按钮可切换或折叠面板；Ctrl+L 将焦点移到搜索框，F6 在侧栏、标签栏与文档之间切换。

## 阅读声明

“更多信息…”菜单可复制名称、来源路径和实体 ID。

正文以 C/IDL 风格的伪代码展示 WinMD 声明，可选择复制。

架构下拉框列出符号支持的 x86、x64、ARM64 架构，每个文档可独立选择。
切换时也会检查泛型实参；实参在目标架构不可用时，保留原文档、阅读位置和架构偏好。

声明注释包含结构体大小、对齐、字段偏移，以及接口槽位和 vtable 偏移。
数值对应当前选择的架构；无法计算时会显示原因。

符号附有 HTTPS 文档链接时，“官方文档”按钮在默认浏览器中打开该链接；否则显示“在线搜索”，使用设置中选择的搜索引擎搜索符号的限定名称。

按 Ctrl+F 或选择“导航 → 正文查找”展开当前文档的查找栏。在正文中选中单行文字后打开查找，可直接以选中文字作为查询。
输入后即时定位匹配，支持区分大小写和全字匹配，并显示当前匹配序号与总数。
F3 查找下一处，Shift+F3 查找上一处；在查找输入框中也可使用 Enter／Shift+Enter。到达首尾时循环，Esc 收起查找栏并返回正文。

在正文中右键可复制选中文本；指向数值及其标签或单位时，还可复制十进制、十六进制或带单位的值。

带下划线的类型引用可按 Ctrl+单击跳转，也可通过右键菜单的“转到声明”打开。
跳转沿用当前文档的来源版本和架构，在预览标签中打开目标；目标已打开时切换到已有标签。无法唯一解析的类型不提供跳转。

闭合泛型引用（如 `IVector<int32>`）会打开保留类型实参的实例声明；成员和嵌套类型引用使用替换后的类型。仍含类型参数的引用跳转到泛型定义。
泛型定义和不同实参的实例分别识别；切换架构、返回和前进均保留实参。实例的“更多信息…”菜单及闭合泛型引用的右键菜单提供“查看泛型定义”。
架构选择框右侧的“类型实参…”按钮用于绑定泛型类型；非泛型声明不显示该按钮。对话框按参数名分别输入类型，打开实例时回填现有实参；支持嵌套实例和 `来源::限定类型名`，参数较多时可滚动或按 Tab 切换。类型无效时保留输入并定位出错项；取消不改变当前文档。
WinRT 泛型实参须符合 WinRT 类型签名，嵌套实例也会检查；`nint`／`nuint` 仅可用于普通 .NET 泛型，不会按架构自动转换为固定宽度整数。
WinRT 接口与委托实例显示 IID。接口实例还显示槽位和受支持的标量 ABI：`HRESULT`、输入／输出参数及返回值输出参数。数组、结构体和运行时类的 ABI 展开会明确提示不支持；声明正文仍是元数据阅读视图，不是可编译头文件。泛型值类型布局及 CLR 约束检查尚未实现。

## 返回与前进

通过“导航”菜单中的“返回／前进”可浏览访问历史，也可按 Alt+左／右键或使用鼠标侧键。
返回时恢复声明、架构与阅读位置；关闭的文档在原内容仍可用时可重新打开。退出后历史清空。

## 工具

从侧栏“工具”打开错误码查询，无需加载 WinMD。

双击、Enter 或右键菜单的“打开”可打开工具。再次打开会激活最近使用的同类窗口；Ctrl+Enter 或“新建实例”打开独立窗口，便于并排比较。

输入代码、选择范围和语言后，点击“查询”或在代码输入框按 Enter 执行；正文可选择复制。代码格式、范围和语言规则见[错误码查询](cli.md#错误码查询)。

修改输入后需重新执行查询。状态栏显示当前工具的查询状态；关闭窗口或退出后不保存输入和结果。

访问历史可切回工具窗口，但不会恢复过去的查询或重新打开已关闭的工具。

## 来源更新与已打开文档

文档保留打开时的内容快照；关闭或重新加载来源后，正文不变，仍可切换架构。重新加载后旧文档会显示提示；从搜索结果重新打开符号可查看更新内容，也可保留旧文档比较。

## 界面与设置

通过“文件 → 设置…”打开设置窗口。

设置窗口的“常规”页可更改界面语言和外观，“搜索”页可按条目类别筛选搜索结果，并选择在线搜索引擎（Google、Bing、百度，默认 Google）。应用搜索引擎设置后，已打开文档的在线搜索也立即生效。
“应用”保存修改但不关闭窗口，“确定”保存并关闭；“取消”仅放弃尚未应用的修改。语言更改在重启后生效，搜索筛选立即生效，不影响已打开文档。

Windows 10 22H2 及更新系统可选择跟随系统、浅色或深色外观，应用或确定后立即生效。更早系统使用原生系统外观；高对比度模式使用系统配色。

窗口布局、来源集合和架构偏好会自动保存。

构建、测试及系统兼容性信息见 [构建与验证](build.md)。
