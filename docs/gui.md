# GUI 设计

## 模块职责

- `app.rs`：UI 线程状态、字体缓存生命周期、启动与消息循环。
- `app/frame.rs`：公共控件、命令分发、主窗口布局和根 DPI 通知。
- `app/sidebar.rs`：常驻工具条、独立面板、两行虚拟列表和 IME 状态。
- `app/sources.rs`：位置发现、来源详情及加载/卸载/重载/替换操作。
- `app/workspace.rs`：文档创建/关闭、文档标签、MDI 激活同步、排列。
- `app/document.rs`：文档内容、相关操作、另一架构打开及焦点恢复。
- `dpi.rs`：DPI 能力探测、旧系统回退、字体和非客户区度量。
- `layout.rs`：几何计算和逻辑位置；`native.rs`：原生操作辅助。
- `resources.rs`、`res/`：语言选择及原生资源。
- `config.rs`：唯一 HKCU 配置根、类型校验、原始路径及加载意图保存。
- `app/settings.rs`：窗口位置恢复/保存、语言设置命令。
- `input.rs`：启动输入约定、原生多选文件框与文件拖放。
- `worker.rs`：后台 Catalog 构建和同步查询，结果通过通道返回。
- `app/catalog.rs`：来源事务、流式搜索、快照绑定的文档查询、实体旧版本判断及打开当前版本。

## 状态与消息

所有 HWND 操作在 UI 线程进行。先读取所需状态并结束借用，再调用 Win32；
状态修改闭包内不得调用可能同步重入窗口过程的 API。

MDI 是活动文档的唯一来源，标签仅映射文档列表。应用发起的创建/关闭集中到工作区；
文档最终移除发生在 `WM_NCDESTROY`，原生默认处理完成后同步标签、投递排列请求。

标题、内容、布局分别更新。文档创建时绑定实体或来源，不创建空文档。
实体文档架构固定，“以另一架构打开”保留同一快照，复用实体、架构和快照均匹配的已有文档；不支持的架构禁用该操作。
来源文档只创建详情和相关操作。文档布局只管理自己的子控件。
快捷键由 RC 加速键表分发；公共区域与文档区域使用 `IsDialogMessageW` 导航。
子控件在获得焦点时记录恢复目标，不在每条消息前扫描文档。

## 元数据与后台任务

启动使用显式 `--winmd` 列表，否则恢复配置的自动加载集合；首次无配置时为空。
GUI 不读取 `WINLEX_WINMD` 或自动加载程序旁文件；CLI 输入规则见 [CLI 文档](cli.md)。
配置中的加载意图与实际加载结果独立，失败不删除意图；临时命令行集合不整体写回配置。
路径以 `OsString`/UTF-16 传递。GUI 添加与显式输入转为绝对路径，保留原始 Unicode/UTF-16；显示文本不参与身份判断。
不同路径条目保留独立位置身份，内容以 SHA256 联动；不把大小相同当作内容相同。
配置目录及程序目录只发现当前层 `*.winmd`，显式刷新重新指纹化，不解析或激活 Catalog。
添加文件、拖放、添加目录只更新发现位置；加载意图由来源详情操作更新。

单后台线程执行核心同步 API，结果通道通过自动重置事件唤醒 UI 消息循环；线程不持有 HWND。
事件由双方共享持有，线程退出也会唤醒 UI 以处理通道断开。任务提交失败会清除等待状态。
新来源集合构建成功后整体替换不可变 Catalog，失败保留旧目录和文档。
构建由核心按 SHA256 去重，加载请求采用递增编号，过期构建结果不会替换新请求。
来源保留原始 `PathBuf`；移除与重载使用原始路径，显示字符串不参与路径身份匹配。
正在进行的文件读取/建库不支持中途打断；UI 不等待它，退出也不等待磁盘 I/O。

搜索请求支持核心取消令牌，旧请求及队列中已取消任务会被丢弃。
文档保留源限定实体 ID、稳定文档 ID、`Arc<Catalog>` 和请求票据。
关闭取消旧请求；活跃来源变化不改写已有文档的解析快照。
初期快照保留整组来源及索引，底层 `Arc<[u8]>` 在快照间共享；尚非逐来源最小保留。
卸载只影响新搜索；旧文档可继续查询原架构/依赖版本。文件变化后标注旧版本，显式重新打开在后台按原完整名称匹配当前来源，歧义时不复用旧 token。

工具条常驻，重复点击当前面板可收起。两个列表保留各自选择与滚动；切换不取消搜索。
输入变化立即取消旧搜索，200 ms 防抖；Enter 清除待执行定时请求并立即搜索；IME 组合期间不搜索。
结果按来源 SHA256、token 顺序以 128 条批次追加；结果通道容量 8，背压等待可取消。
单列虚拟 ListView 固定两行、隐藏表头、无横向滚动；完整信息由原生 tooltip、虚表可访问文本以及 F1 提供。
实体文档直接显示核心返回的结构化元数据及相关操作。

主窗口 DPI 通知按资源更新、建议窗口矩形、公共布局、文档布局的顺序处理。
保留原生 MDI 默认消息处理；自由排列的位置只在用户操作边界记录。
顶层窗口用 `WM_SIZING` 约束交互缩放，避免 `WM_GETMINMAXINFO` 的最小尺寸干扰 DPI 向下缩放。
普通布局只更新几何；DPI 和系统设置变化更新字体，旧字体在控件重新绑定后释放。
结果列宽跟随实际客户区。
底部使用原生 StatusBar，由控件自行停靠并报告实际高度；主窗口布局预留该高度。
状态文本通过 `SB_SETTEXTW` 更新，长信息提供悬停提示。

## 资源约定

固定 UI 文案放入 `res/en-US.rc` 和 `res/zh-CN.rc`；菜单使用原生 MENU 资源。
选定语言的字符串在启动时验证并缓存；加速键使用语言中立的 ACCELERATORS 资源。
协议值、窗口类名、技术诊断及最小错误兜底可保留在代码中。
`resource.h` 是资源和命令 ID 的唯一来源，构建时生成 Rust 常量。
固定选项集中定义模型值和显示资源 ID，不能从翻译后的文案推断模型值。

语言在启动时选择：`auto` 使用系统 UI 语言，简体中文使用中文资源，其余回退英文；
也可指定 `en-US` 或 `zh-CN`。直接按语言读取原生资源，兼容 XP，不依赖新版线程语言 API。

## 配置与测试隔离

默认根为 `HKCU\Software\Winlex`；启动时可通过 `WINLEX_CONFIG_ROOT` 指定 HKCU 相对路径。
全进程使用同一个配置对象。测试必须使用独立根并清理；重启测试复用同一根。

版本 1 使用 `Version`（DWORD）、`Language`（SZ）、`Files/Directories/AutoLoad`（MULTI_SZ）、
`SidebarWidth/ActivePanel`（DWORD）及 `Window`（BINARY：六个小端 32 位值，屏幕 x/y、正常宽/高、DPI、最大化标志）。
`PanelCollapsed`（DWORD）保存面板收起状态。
缺失或无效值回退默认；不支持的版本采用只读默认值并提示，不覆盖未来版本配置。

语言配置支持 `auto/en-US/zh-CN`；菜单修改后下次启动生效。
`WINLEX_DPI` 提供测试覆盖，默认 Auto，不持久化 DPI 模式。
窗口恢复按目标 DPI 缩放正常尺寸并限制在当前工作区；最大化状态独立保存。

`gui.rc` 统一嵌入菜单、字符串、版本信息和清单；版本信息来自 Cargo 包版本。
清单声明 common-controls v6、asInvoker 和系统兼容性，DPI awareness 由运行时选择。
资源文件使用 UTF-8，RC 显式指定代码页；换行遵循本仓库 `.gitattributes`。

验证包括双语资源完整性、占位符一致性、实际控件文案、固定架构及另一架构文档复用，
运行方式见[构建与验证](build.md)。
