# GUI 使用指南

## 打开与管理文件

通过“打开文件”（Ctrl+O）、来源面板的打开按钮或拖放，打开一个或多个 WinMD 文件。
加载完成后即可搜索其中的符号。来源列表显示文件名、加载状态、大小和所在目录。
悬停可查看完整路径和精确字节数。
选中来源后可重新加载或关闭，也可通过右键、菜单键或 Shift+F10 打开菜单，复制完整路径。
重新加载时显示进度状态，失败时保留原来源，并可在悬停提示中查看原因。当前已加载的数据仍可继续使用。

普通启动会恢复上次成功打开的来源集合；首次启动时可自行选择文件。
使用 `winlex-gui [FILE ...]` 启动，可指定一个或多个文件，也可将文件拖到 EXE 或快捷方式上启动。
指定文件路径启动的是临时会话，其中的来源操作不影响普通启动时恢复的集合。

## 搜索与预览

输入查询后会自动搜索，按 Enter 可立即执行搜索。右侧下拉框提供两种方式，切换时保留当前输入：

- **快速搜索**（默认）：同时尝试模糊名称、数字等值、字符串常量子串和 GUID，每个实体只显示一次；GUID 自动识别要求至少 4 个规范化十六进制字符。
- **条件搜索**：明确指定字段和操作，例如 `name contains "access" and value = 5`、`value contains "Windows"`、`value >= 1.45 and value < 1.55`、`value = nan or value = inf`。支持 AND、OR、NOT 和括号。

名称不区分大小写。快速搜索支持按顺序输入不连续字符；查询不含 `.` 或 `+` 时匹配短名称，否则匹配完整限定名；末尾 `.`／`+` 可浏览名称范围。条件中的 `name` 和 `fullname` 明确指定字段。
数字 `5`、浮点数 `5.0` 和字符串 `"5"` 含义不同；浮点等值 `1.5` 与 `1.50` 等价，范围需显式指定。`nan` 匹配任意 NaN，`inf`／`-inf` 匹配正负无穷。
悬停搜索框可查看当前搜索方式的简要语法和示例。输入未完成或条件无效时，状态栏提示错误并清空旧结果。通过“帮助 → 搜索语法…”查看完整说明，完整规则见 [CLI 与查询接口](cli.md)。
快速搜索优先显示精确命中，其次为 GUID 片段、文本匹配和模糊名称；模糊名称按匹配度排列。同级和组合条件按来源与记录标识排列。

结果显示名称、类别、常量值或所属类型、架构及命名空间。共有定义省略架构；GUID 使用 `{...}` 表示，完整 GUID 可在声明中查看。
匹配的名称、字符串或数值会突出显示。
悬停可查看完整名称、来源路径和记录标识；不同来源的同名实体保留独立结果。

- 单击结果或按空格预览声明。连续预览会复用同一个标签，方便快速浏览。
- 双击结果或按 Enter，可固定文档并进入正文。
- 双击预览标签也可将其固定。
- 按 Ctrl+Enter，可在新文档中打开结果，创建副本用于并排比较。
- 再次打开相同来源版本和架构的同一符号，会切换到已有文档。

右键、菜单键或 Shift+F10 可打开结果菜单，打开文档、在新窗口打开或复制完整名称。有值的条目还可复制值；整数另提供十六进制复制，负数按原类型位宽表示。适用的整数可直接“搜索错误码”：激活最近的错误码工具实例，以自动范围和默认语言立即查询。

标签显示图标和标题，预览标签使用斜体，悬停可查看完整标题。中键、右键菜单或 Ctrl+F4 可关闭文档，拖动标签可调整顺序；标签较多时可用滚轮横向滚动。
标签栏获得焦点后，左右键切换标签，Home／End 跳到首尾，Ctrl+Shift 配合这些键可调整标签顺序，Enter 进入正文；右键、菜单键或 Shift+F10 打开标签菜单。
“窗口”菜单提供关闭文档、平铺、自由排列和最大化操作。
侧栏按钮可切换或折叠面板；Ctrl+L 将焦点移到搜索框，F6 在侧栏、标签栏与文档之间切换。

## 阅读声明

文档顶部显示名称、种类、命名空间／所属类型和来源文件名。“更多信息…”菜单提供完整来源路径和实体 ID，选择菜单项即可复制；也可复制名称、限定名称和来源文件名。

正文以 C/IDL 风格的伪代码展示 WinMD 中的声明，采用等宽字体和语法着色，随窗口宽度自动折行，可选择复制。

架构下拉框列出符号支持的 x86、x64、ARM64 架构，每个文档可独立选择。
打开其他结果时，会优先沿用当前文档的架构；不适用时使用保存的偏好或符号支持的架构。
按 Ctrl+Enter 打开的新文档使用保存的架构偏好。

声明注释包含结构体大小、对齐、字段偏移，以及接口槽位和 vtable 偏移。
数值对应当前选择的架构；无法计算时会显示原因。布局大小和字段偏移以十进制显示，虚表偏移以十六进制显示。整数枚举和常量附带十六进制注释，字符串常量注明 UTF-16 代码单元数。

符号附有 HTTPS 文档链接时，“官方文档”按钮在默认浏览器中打开该链接；否则显示“在线搜索”，使用 Google 搜索符号的限定名称。

按 Ctrl+F 或选择“导航 → 正文查找”展开当前文档的查找栏。在正文中选中单行文字后打开查找，可直接以选中文字作为查询。
输入后即时定位匹配，支持区分大小写和全字匹配，并显示当前匹配序号与总数。
Enter／F3 查找下一处，Shift+Enter／Shift+F3 查找上一处；到达首尾时循环并提示。
Enter 快捷键在查找输入框中使用。Esc 收起查找栏并返回正文，保留当前匹配。

在正文中右键可复制选中文本；指向数值及其标签或单位时，还可复制十进制、十六进制或带单位的值。
也可使用菜单键或 Shift+F10 打开上下文菜单。

带下划线的类型引用可按 Ctrl+单击跳转，也可通过右键菜单的“转到声明”打开。
光标位于引用内时，菜单键或 Shift+F10 提供同一操作。
跳转使用来源文档的元数据快照和架构，在唯一预览标签中显示目标；来源是预览时复用其标签，来源已固定时保留来源标签。
目标已打开时切换到已有标签。可通过“返回”恢复之前浏览的声明和阅读位置。
只有当前快照能唯一解析的类型提供跳转。

## 返回与前进

通过“导航”菜单中的“返回／前进”可浏览访问历史，也可按 Alt+左／右键或使用鼠标侧键。
历史包含预览、打开、引用跳转、切换文档和切换架构。返回时恢复正文选区与阅读位置。

历史中的预览仍复用预览标签，已固定的文档保持固定。返回后打开其他目标会开始新的前进路径。

关闭过的文档在对应内容版本仍可用时，可以作为预览重新打开；已不可用的旧版本会自动跳过。
全部文档关闭后，“返回”可恢复最近的有效位置。
历史在退出后清空。

## 工具

侧栏的“工具”入口列出独立查询工具。错误码查询无需加载 WinMD，支持自动、Win32、HRESULT、NTSTATUS、CRT errno 和自定义模块范围。

单击选择工具，双击、Enter 或右键菜单的“打开”可打开工具，窗口始终固定，不替换声明预览。再次打开会激活最近使用的同类实例；Ctrl+Enter 或“新建实例”打开独立窗口，便于并排比较。

输入代码、选择范围和语言后，点击“查询”或在代码输入框按 Enter 执行。整数语法与搜索一致，支持正负号、0x 十六进制、0b 二进制和八进制；前导零表示八进制，例如 010 为 8。不接受符号名称或浮点数。

自动模式分别查询 Win32、HRESULT 和 NTSTATUS，并展示匹配结果。HRESULT 可显示关联的 Win32 错误。自定义模块按完整消息 ID 查询指定文件的消息表，不回退到系统消息。

CRT errno 需要显式选择，查询系统 `msvcrt.dll` 的 Microsoft CRT 消息，不代表 UCRT 或 POSIX 的完整错误码表。该范围的语言固定为英文，语言选择控件不可编辑；未知值和表内空缺显示消息未找到，不回退到 Win32。

语言的“自动选择”使用 Windows 的消息语言选择规则；指定 LANGID 时只请求该语言。不同消息可用的语言可能不同。结果注明查询参数、消息来源和语言信息，正文可选择复制。NTSTATUS 和自定义模块展示完整资源模板，保留原有占位符，并显示实际资源语言；语言中立资源与自动选择分别标注。

将鼠标停留在代码输入框上可查看输入格式提示。修改输入不会自动执行查询，旧结果仍对应上次执行的参数。底部状态栏显示当前工具实例的查询状态。工具输入和结果只在当前实例内保留，关闭或退出后不保存。

工具与声明共用访问历史。返回工具窗口时保留其当前输入和结果，不回滚到之前的查询；关闭工具后，历史跳过该实例，不自动重新创建。

## 来源更新与已打开文档

文档保留打开时的内容快照。关闭或重新加载来源后，已有文档的正文保持不变，
仍可切换架构查看该快照的声明。

重新加载来源后，旧文档会显示旧快照提示。从搜索结果打开符号即可查看更新后的内容，
也可以保留旧文档进行比较。

## 界面与设置

通过“文件 → 设置…”打开设置窗口。

设置窗口的“常规”页可更改界面语言和外观，“搜索”页可按条目类别筛选搜索结果。
确定后保存修改，取消则放弃修改。语言更改在重启后生效，搜索筛选立即生效，不影响已打开文档。

Windows 10 22H2 及更新系统可选择跟随系统、浅色或深色外观，确定后立即生效。更早系统使用原生系统外观；高对比度模式使用系统配色。

窗口布局、来源集合和架构偏好会自动保存。

界面随显示缩放调整尺寸，字体跟随系统设置。
构建、测试及系统兼容性信息见 [构建与验证](build.md)。
